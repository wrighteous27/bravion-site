Bravion email signature (logo on the left)

Replace the bracketed text, then select everything inside the white box (click just before the logo and drag to the end of the last line), copy, and paste it into your signature settings. Open this page in Chrome or Edge, not inside a preview window, so the copy includes formatting.

  1. Outlook for Windows (classic): File → Options → Mail → Signatures → New → paste into the edit box → Save. Set it as the default for new messages and replies.
  2. New Outlook and Outlook on the web: Settings (gear) → Accounts → Signatures → New signature → paste → Save.
  3. Outlook for Mac: Outlook → Settings → Signatures → + → paste → Save.
  4. Gmail: Settings → See all settings → General → Signature → Create new → paste.

The logo is a small image hosted with the Bravion website, so Outlook keeps it in place. It sits on a small charcoal badge so it reads clearly whether the reader uses light or dark mode. If a recipient's email blocks images, they will see the company name in its place until they allow images.

If the logo shows up blank after pasting (some Outlook versions won't pull in web images):

  1. Download the logo (right-click → Save image as, if it opens in a new tab).
  2. In your signature editor, click the blank image and delete it.
  3. Click the picture icon in the signature editor toolbar, choose the downloaded file, and insert it.
  4. If it comes in large, right-click it → Size and Position (or drag a corner) and set the width to 84 px. Save.

Inserting it this way stores the logo inside the signature itself, so it always shows.
