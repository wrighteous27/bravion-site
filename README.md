# Bravion website (draft)

Draft website for Bravion Envelope Systems Inc., shared for team review. Static HTML, CSS and JavaScript with no build step, served by GitHub Pages from the `main` branch.

- Content, product lines, contact routing and photos: `config.js`
- Design themes: `themes.js` and `layouts.css` (current theme: `slab2`, Precast Slab Friendly)
- Search engines are asked not to index the site (`robots.txt` and a `noindex` meta tag) while it is a draft.
